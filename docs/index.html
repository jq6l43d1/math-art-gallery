Math Art Gallery

Every piece on these walls was drawn by an equation. No brushes, no hand tuning of pixels, just a few lines of math iterated millions of times. Click any frame for the full resolution image.

No. 1

Clifford Attractor

x' = sin(a y) + c cos(a x)
y' = sin(b x) + d cos(b y)

a = -1.3, b = -1.3, c = -1.8, d = -1.9, 10 million points

Two lines of trigonometry, iterated ten million times. Each point is computed from the one before it, and the orbit never settles into a repeating loop, yet it always traces the same tangle of ribbons. Darker ink means more visits.

No. 2

Peter de Jong Attractor

x' = sin(a y) - cos(b x)
y' = sin(c x) - cos(d y)

a = 1.4, b = -2.3, c = 2.4, d = -2.1, 12 million points

A close cousin of the Clifford map with the cosines subtracted instead of added. The same idea, a different personality: it folds into smoke instead of ribbons. Rendered like a long exposure of light on black.

No. 3

Lorenz Attractor

dx/dt = s (y - x)
dy/dt = x (r - z) - y
dz/dt = x y - b z

s = 10, r = 28, b = 8/3, RK4 with dt = 0.002, 6 trajectories

Edward Lorenz's simplified weather model, the original butterfly. Six particles start a hair apart and are carried along the flow. Within seconds they disagree completely about where they are, but all of them keep circling the same two wings.

No. 4

Julia Set

z' = z^2 + c
c = -0.8 + 0.156i

500 iterations, smooth escape-time coloring

Every pixel is a starting value of z. Square it, add c, repeat. Points that stay bounded forever form the set; the color outside shows how quickly each point escaped. The edge is infinitely detailed.

No. 5

Barnsley Fern

pick one of four affine maps at random
(x, y) -> A (x, y) + b

4 maps chosen with probability 1%, 85%, 7%, 7%, 8 million points

A fern drawn by rolling dice. Each map is a simple stretch, rotate and shift; one makes the stem, one makes each leaf a smaller copy of the whole, and two make the first left and right leaflets.

No. 6

Harmonograph

x(t) = e^(-d1 t) sin(f1 t + p1) + e^(-d2 t) sin(f2 t + p2)
y(t) = e^(-d3 t) sin(f3 t + p3) + e^(-d4 t) sin(f4 t + p4)

f = 3, 2, 3, 2.006, damping around 0.005 per second

A Victorian drawing machine in software: a pen moved by swinging pendulums that slowly lose energy. Frequencies close to a simple ratio, but not quite, make the figure drift and spiral inward.

No. 7

Maurer Rose

r = sin(n theta)
connect the points at theta = k d degrees, k = 0..360

n = 6, d = 71

Start with the rose curve r = sin(6 theta), then ignore it and walk around it in jumps of 71 degrees, joining each landing spot with a straight line. The rose (in red) is hidden inside its own web.

No. 8

Phyllotaxis

theta_k = k * 137.508 degrees
r_k = sqrt(k)

1,500 seeds, golden angle

How a sunflower packs its seeds. Each new seed is placed one golden angle around from the last. Because the golden ratio is the 'most irrational' number, the seeds never line up into gaps, and the spiral families you see come in Fibonacci numbers.
