No. 23

Domain Coloring

Complex function, 2026. Python and numpy.
f(z) = (z^2 - 1)(z - 2 - i)^2 / (z^2 + 2 + 2i)
hue = arg f(z),  brightness bands = log |f(z)|

A way to draw a complex function, which takes a 2D input to a 2D output and can't be graphed the usual way. Color shows the direction of f(z) and the shaded rings show its size. Zeros are where all the colors meet; the double zero at 2 + i spins through the rainbow twice. Poles look the same with the colors running backwards.

A complex function takes a point in the plane and returns another point in the plane, so an ordinary graph would need four dimensions. Domain coloring, a name coined by Frank Farris, paints the output onto the input instead: the hue shows which direction the output points and the brightness shows how big it is.

This function has simple zeros at 1 and -1, a double zero at 2 + i, and two poles where z^2 = -2 - 2i. Around each zero the colors circle once for each order of the zero; around the poles they run backwards. The rings step every time the size of f(z) doubles, and faint spokes mark every 30 degrees of phase.
