No. 17

Seahorse Valley

Escape-time fractal, 2026. Python and numpy.
z' = z^2 + c,  z_0 = 0
c = the pixel

A zoom into the Mandelbrot set, in the crease between its main body and the big round bulb to the left. Every swirl here is made of smaller swirls, and tiny complete copies of the whole set are hidden along the filaments.

Benoit Mandelbrot made the set famous in 1980 with computer plots made at IBM. It is the set of numbers c for which z^2 + c, repeated starting from zero, never runs off to infinity. Its boundary is so tangled that it has the same dimension as a filled-in area.

Seahorse Valley is the narrow gap between the main heart-shaped body and the round bulb to its left. This view is about 500 times narrower than the whole set and uses up to 1,500 iterations per pixel. The colors cycle through a cosine palette as the escape count rises, so detail close to the set gets as much color as the background.

centered on -0.7453 + 0.1127i, about 1/500th the width of the full set, 1,500 iterations
