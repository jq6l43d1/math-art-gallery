No. 2

Peter de Jong Attractor

Strange attractor, 2026. Python and numpy.
x' = sin(a y) - cos(b x)
y' = sin(c x) - cos(d y)

A close cousin of the Clifford map with the cosines subtracted instead of added. The same idea, a different personality: it folds into smoke instead of ribbons. Rendered like a long exposure of light on black.

Each new point depends only on the one before it, so the whole image is one rule applied over and over. Most choices of a, b, c and d give a thin loop or a shapeless cloud. A few, like these, give folded sheets with real depth, and finding them is mostly patient trial and error.

This one is rendered as light instead of ink. The number of visits to each pixel is mapped through a palette that runs from black through deep blue to white, so the most visited folds glow like a long-exposure photograph.

a = 1.4, b = -2.3, c = 2.4, d = -2.1, 12 million points
