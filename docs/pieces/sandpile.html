No. 16

Abelian Sandpile

Cellular automaton, 2026. Python and numpy.
drop N grains on one cell
any cell with 4 or more grains gives 1 to each neighbor

Pour sand onto a single square of a grid. Whenever a square holds four grains it topples, passing one to each neighbor, which may topple in turn. When everything finally settles, this fractal of nested triangles and ovals is what's left.

Physicists Per Bak, Chao Tang and Kurt Wiesenfeld introduced the sandpile in 1987 as a model of self-organized criticality: a system that drives itself to the edge of an avalanche. Deepak Dhar later proved the abelian property, that topplings can happen in any order without changing the outcome.

Here 65,536 grains start on one cell. Each color is the number of grains left on a cell when everything settles: 0, 1, 2 or 3. For speed, every unstable cell topples as many times as it can at once, which by the abelian property gives exactly the same final pile.

N = 2^16 grains, colored by 0, 1, 2 or 3 grains left
